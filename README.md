# EuroVis 2027 Workshops Timeline

A responsive, accessible single-page timeline for the EuroVis 2027 Workshops call in Stuttgart, Germany.

The page intentionally presents only the currently published Workshop milestones:

- Proposal Submission — Monday, October 12, 2026
- Notification — Monday, October 26, 2026
- Both deadlines: 23:59 Anywhere on Earth (AoE)

Each milestone card expands with context and links to the [official EuroVis 2027 Workshops call](https://eurovis27.github.io/web/submissions/workshops/). Further dates are not added until officially announced.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Accessibility

- Semantic headings, time elements, and ordered timeline structure
- Native, keyboard-operable expandable details
- Visible keyboard focus styles
- Responsive layout that changes from alternating desktop cards to a single mobile flow
- Reduced-motion preference respected
